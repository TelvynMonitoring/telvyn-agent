## Hardcoded secret formats (Java IAST)

`telvyn-java-agent/src/main/resources/iast-secret-patterns.tsv` lists the secret
formats that the Java IAST looks for in application string literals. The file is
generated by `tools/iast-secrets/generate.py` from the public token formats of each
service (fixed prefix, alphabet and length).
